# TDD-цикл для Book і Category (SCRUM-6)

## Вимоги

Книга має непорожню назву, одну наявну категорію та щонайменше одного автора. Назва категорії також не може бути порожньою або пробільною. Колекція авторів книги не може бути `null`, порожньою або містити `null`-елементи.

## Red

На початковому етапі Red було запущено 21 тест: 13 успішних і 8 невдалих. Невдалі тестові сценарії очікували відхилення порожньої назви категорії, `null`-категорії книги, `null`-колекції авторів, порожньої колекції авторів і `null`-елемента в колекції.

## Green

До конструкторів `Category` і `Book` додано необхідні перевірки: перевірка назви, перевірка наявності категорії та колекції авторів, заборона порожньої колекції і `null`-елементів. Колекцію авторів скопійовано в масив і збережено як доступну лише для читання колекцію.

Користувач підтвердив, що поточний набір тестів став зеленим.

## Refactor

Фактичного рефакторингу реалізації не потребувалося: конструктори залишилися невеликими, дублювання перевірок і зайвих абстракцій немає. Поведінку `Book` і `Category` під час завершення блоку не змінювали.

## Роль GitHub Copilot

GitHub Copilot допомагав із плануванням тестів Red, створенням мінімальної моделі, реалізацією перевірок Green та переглядом реалізації для виявлення дублювання. Зміни переглядав користувач, а перевірку тестів виконано вручну в поточному рішенні.
