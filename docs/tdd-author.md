# TDD-цикл для Author (SCRUM-6)

## Вимога

Автор не може мати порожнє або пробільне ім’я. Конструктор `Author(string name)` має відхиляти таке значення і зберігати лише непорожнє ім’я у властивості `Name`.

## Red

Тест `CreateWithEmptyName_ShouldThrowArgumentException` очікував `ArgumentException` для `new Author("")`, однак конструктор лише присвоював `Name`.

Результат: 1 тест запущено, 1 невдалий. xUnit повідомив: `No exception was thrown`.

## Green

До конструктора `Author` додано перевірку `string.IsNullOrWhiteSpace(name)`. При порожньому або пробільному імені викидається `ArgumentException` із зрозумілим повідомленням і `nameof(name)`.

Результат: 1 тест запущено, 1 успішний.

## Refactor

Наявний тест порожнього імені явно розділено на Arrange, Act і Assert: порожнє ім’я винесено в змінну, створення автора — в `Action`, а перевірку винятку залишено в `Assert.Throws<ArgumentException>`.

Поведінку тесту та `Author` не змінено під час рефакторингу.

## Додаткове покриття

До тестового класу додано:

- `Theory` для значень `" "`, `"   "` і `"\t"`, які мають відхилятися;
- `Fact` для точного збереження імені `"Леся Українка"` у `Name`.

Це розширення покриття вже реалізованої перевірки пробілів, а не окремий підтверджений Red → Green → Refactor-цикл.

## Роль GitHub Copilot

GitHub Copilot допомагав із плануванням, підготовкою першого тесту, реалізацією перевірки та покращенням тестів. Зміни переглянув користувач з урахуванням поточних файлів. Тести запускалися вручну через Visual Studio/Test Explorer.

dotnet test tests/Library.UnitTests/Library.UnitTests.csproj
